# 骑士设计 DNA + 想象力引擎

> 本文件解决一个矛盾：**共性让角色不走偏，想象力让角色比原版更出彩**。
> 默认走「独创」，**不套用任何既有骑士的复刻模板**（Build / W / Faiz / Decade 等）。
> 复刻模板仅在用户明确点名「我要复刻某骑士」时才启用。

---

## 0. 两条铁律

1. **共性（DNA）= 底线，不是灵感来源**。DNA 是从历代骑士抽象出的**结构共性**，它保证「出来还是骑士」，但不规定长什么样。
2. **想象力 = 差异，来自维度组合**。不许直接挪用既有骑士的配色/道具/招式；灵感必须来自「非骑士领域」的再组合。

> 判断标准：如果一个设计能被一句话概括成「XX 骑士的换色版」，就是失败的。

## 1. 共性层：骑士设计 DNA（11 条，缺一条就走偏）

| # | 共性 | 具体要求 | 为什么 |
|---|---|---|---|
| D1 | **腰部装置** | 腰间必有明确的「装置」（driver），是变身与能量中枢，不是普通皮带扣 | 最强识别符号，骑士的"心脏" |
| D2 | **可命名拟态** | 必有一个能一句话说清的原型母题（不只是"帅"），且**能在头部/胸甲/装饰上被读出来** | 骑士是"拟态英雄"，母题是灵魂 |
| D3 | **发光非人眼** | 单眼横缝或复眼，必发光；**绝不出现人类眼睛** | 非人标记，去掉就变普通装甲 |
| D4 | **不对称 / 分区（DNA 层可选，**本技能默认强制**）** | 左右异色、半身异质、单侧武装等分区在 **DNA 层是可选强化**（顶流 Kuuga / Faiz / Kabuto / Black 多为对称，对称同样能出顶级设计）；**但本技能的默认产出风格把「不对称」设为强制——完全对称视为不合格**。必须至少有一处**结构级**不对称：单侧重型肩甲 / 单侧披风 / 冠饰偏置 / 腰带扣偏心 / 双腿甲片不同规格 / 单臂武装，而不是随机色块拼贴 | 本技能走 KR 骨架 × Warframe 高分件复杂度路线，对称会让复杂分件显得呆板；非对称才出"设计过"的帅气高级感 |
| D5 | **剪影放大件（可选强化）** | 肩甲 / 围巾 / 触角 / 光轮 / 碎片环等放大剪影元素是**常见强化手段，但非强制**（Kuuga / Faiz / Kabuto 极简无大件仍顶级）。**主骑普遍无尾巴——尾巴是怪人（kaijin）特征，禁止写尾巴**（"尾迹"仅指运动残影，非实体尾） | 强化辨识度，但不是定义项 |
| D6 | **人类 → 骑士同一性** | 变身保留同一人（体型/脸型/气质一致），且有转换过程 | 骑士是"人变成的"，不是召唤物 |
| D7 | **终结设计** | 有明确的决定性一击（外壳仍是骑士踢或武器必杀二选一，但**内核必须母题化**） | 战斗的落点，没有就散；写法见 `henshin-finisher-ability-engine.md` |
| D8 | **代价 / 限制**（强烈建议） | 变身或使用力量要付代价、有条件限制 | 戏剧张力来源，也是独创性的入口 |
| **D9** | **变身锚点（平成惯例，强烈推荐）** | 四连仪式：**取出可辨识道具 → 与腰间装置交互（插入 / 嵌入 / 咬合 / 贴合）→ 一个明确的机械操作（转柄 / 拉杆 / 拍按钮 / 盖印 / 拧 / 拨）→ 装置响应（发光 / 报号 / 机械音）**。是**平成以降**的主流识别子，强烈推荐沿用；但**非全世代铁律**——昭和（1号 / Black）仅靠腰带 + "变身" pose，Kuuga 用 Arcle 触摸，均无插入道具。创新只放在道具与操作内容 | 平成 25 年最强识别子之一（Gavv 2024-25 仍「张嘴→插入饱藏→闭嘴→转把手→按按钮」）；缺失会明显弱化"这是骑士"的识别，但昭和证明并非绝对不可省 |
| **D10** | **硬表面法则（躯体硬，配件可软）** | 装甲**主体**必须是可辨的硬表面分件（金属 / 陶瓷 / 黑曜石 / 晶体 / 硬化几丁质…），有分面、接缝、厚度；**软 / 有机只能作为「形」与「层」**，不能作为基材。但**软质配件允许**——围巾 / 披风 / 布质飘带是骑士传统（昭和红围巾即软布），天线也可柔性。**软烂躯体（黏液 / 触须 / 无分面肉块）才是怪人** | 骑士与怪人的分界线在"躯体是否硬分件"；软质配件不越界，软烂躯体才越界（参见反派 Breed Gavv 的黑污泥形态）。判据：**看不出硬表面分件 → 已滑向怪人** |
| **D11** | **音效锚点（平成惯例，强烈推荐）** | 装置在 D9 四连**每一步操作**都发出**口号式音效（call-out）**——取道具时的**启动口号**、与装置交互时的**交互口号**、明确操作时的**操作口号**、装置响应时的**报号**（喊出骑士 / 形态名）；之后才是序列音与定格静默；必杀须有自己的**命名 call**。口号是能被听见的单词 / 短语（如 Vail 印章启动"独角仙！"→ 盖印"交易成立！"；Faiz 待机"Standing By"→"Complete！"），不是纯机械哔声。**可创新**：每步口号的音色、与母题同构的音形（回声用延迟叠音、鮟鱇用低频脉冲）、节奏；**默认语言**：音效 call-out 一律**日语发音**（片假名 / 罗马字标注，如「エコー！」「サイレンス！」；除非用户明确指定其他语言）；**不可创新**：D9 四连每步都必须有对应口号式音效、装置响应必须报出名字（"Kamen Rider!" 式 call-out）、必杀必须有命名 call——去掉任一项就丢失假面骑士的听觉识别 | 音效与视觉 D9 并列，是平成以降 25 年最强识别子之一（Vail 2022：印章启动"独角仙！"→ 盖印"交易成立！"→ 序列"灾厄涌现！破坏！世界！千奇百怪！假面骑士——Vail！"；Faiz：待机"Standing By"→"Complete！"→ 必杀"Exceed Charge！"）。观众靠**看见道具操作 + 听见装置每步喊口号 + 报出名字**三重确认"这是假面骑士"。**音效是分镜（B/C）资产：生图流（A）是静态图、听不见声音，不落地音效** |

**D1–D3、D6–D7、D10（躯体硬）是硬底线；D5 为可选强化；D8 是让角色"有故事"的关键加分项；D9（平成惯例）、D11（音效，仅分镜流）为强烈推荐项，非全世代铁律。**

> ⚠️ **D4 的双层口径（别混用）**：**DNA 层**——不对称是可选强化，对称不是错误（顶流骑士多数对称，审计结论不变）；**本技能产出层**——**默认强制不对称**，因为本技能走的是 KR 骨架 × Warframe 高分件复杂度的融合风格，对称会显呆板。写提示词时按"强制"执行；若用户明确要对称设计，按用户要求覆盖本默认值并说明。

> **关于 D11 的创新边界**（与 D9 同构）：音效**结构不可动**——D9 四连每一步都必须配一个口号式 call-out；但下面每一项都能（也应该）母题化创新——
> ① **每一步的口号内容**：取道具时的启动口号（Vail"独角仙！"）、交互时的交互口号、操作时的操作口号（Vail 盖印"交易成立！"）、响应时的报号（喊出骑士名）——口号可以是单词、短语、拟声，关键是**不是纯机械哔声，而是装置在每步都"喊出意义"**；
> ② **报号的语言与音色**：机械电子音 / 生物音（脉动、振翅）/ 环境音（回响、水声）皆可，关键是「装置一激活就喊出名字」这一动作；
> ③ **序列音的节奏**：急促连珠 / 庄严慢板 / 倒放 / 母题化的音形（回声用延迟叠音、日食用吞光后的静默、鮟鱇用低频脉动）；
> ④ **必杀命名 call 的风格**：与终结内核一致（概念结算 → 报出被抽走之物；收容 → 报出封印之名）；
> ⑤ **专属于该腰带的机械音材质感**：金属咔哒 / 玻璃碎裂 / 生物脉动 / 晶体共鸣。
> 一句话：**听觉仪式守旧（每步喊口号 + 报号 + 命名 call），口号内容全部换新**——与 D9「视觉仪式守旧，内容换新」是同一套方法论的双胞胎。
> ⚠️ **音效是分镜（B/C）资产，不是生图（A）资产**：生图流产出的是静态角色设计图，图里听不见声音，所以 A 生图流**不写音效字段**；音效只在 B 变身流 / C 战斗流的分镜提示词里落地（见 `henshin-finisher-ability-engine.md` 1.4）。

> **关于 D9 的创新边界**：四连是**平成主流范式、强烈推荐**，但下面每一项都可以（也应该）创新——
> ① **道具是什么**（瓶罐 / 记忆体 / 硬币 / 卡带 / 饱藏 → 换成你母题里的东西：一块声石、一枚菌核、一片日食盘、一块镜刃、一颗诱饵光囊）；
> ② **操作是什么**（转 / 拉 / 按 / 盖印 / 拧 / 吹 / 咬 / 掰）；
> ③ **装置如何响应**（发光 / 报号 / 机械咬合声 / 反向输出）；
> ④ **之后的介质与生长方式**（这才是想象力主战场，见 `henshin-finisher-ability-engine.md`）。
> 一句话：**仪式结构守旧，内容全部换新**——像爵士标准曲，和声进行不动，旋律随便写。

> **关于 D10 的软质母题怎么落地**（以 Gavv 为证）：主题可以是**软**的（软糖 / 棉花糖 / 巧克力），但必须翻译成**硬甲的形状语言**——
> 蓬松 → **蓬起的厚甲板**（棉花糖形态走相扑/雪男轮廓）；流淌 → **垂坠的装甲流线**（巧克力）；酥脆 → **波浪状甲片**（薯片）。
> 即：**软是"形"，硬是"体"**。菌丝可以拟态，但输出的是**陶瓷化 / 几丁质硬化的菌甲**，孢子只能从**甲缝里溢出**，不能替代甲片本身。**例外**：围巾 / 披风等软质**配件**是骑士传统（昭和红围巾），允许存在，不算越界。

## 2. 想象力层：9 个生图发散维度（A–I）＋ 维度 J（音效，仅分镜流）

> 每个维度都**刻意绕开既有骑士的常用答案**。做法是：从骑士 IP 之外取材（自然、物理、材料、人体、日常物、抽象概念）。
> 生成时至少跨 **4 个维度**做非常规选择，越多越独创。

### A. 拟态母题（Motif）—— 不局限于生物与载具
| 类别 | 可选的非常规原型 |
|---|---|
| 天象 / 天气 | 日食、雷云、雾、虹、霜、沙尘暴、极光 |
| 地质 / 矿物 | 熔岩、水晶簇、冰川、沙漠、钟乳石、锈蚀 |
| 声音 / 感知 | 回声、静默、噪音、盲区、余像 |
| 时间 / 状态 | 锈蚀、正午、子夜、凝固、蒸发 |
| 抽象概念 | 分形、莫比乌斯、黄金比、悖论、概率 |
| 深海生物 | 鮟鱇、管虫、水母、鹦鹉螺、深海鳞角腹足蜗牛 |
| 天体 / 宇宙 | 脉冲星、黑洞、日冕、陨石、潮汐 |
| 日常物 | 伞、钥匙、镜子、墨水、折纸、钟表、灯笼 |
| 微生物 / 菌类 | 菌丝、孢子、病毒衣壳、地衣 |
| 乐器 | 管风琴、弦、鼓皮、音叉 |

### B. 材质（Material）—— 不局限于金属与树脂（但受 D10 硬表面法则约束）
黑曜石玻璃、陶瓷釉 / 冰裂纹、液态金属、绷带织物、晶体生长、珊瑚 / 骨骼、锈蚀铁、发光苔藓、折纸、水墨、熔岩石、珍珠母贝、碳纤维编织、冰、烟、漆器、菌膜、羽毛、陶土、玻璃纤维、沥青。

> ⚠️ **软 / 有机的正确用法**（违反 D10 就会变怪人）：
> - ✅ 母题可以软（菌丝、孢子、软糖、雾），但输出必须是**硬化后的形态**：陶瓷化菌甲、几丁质硬化甲、结晶化的雾。
> - ✅ 软质只允许出现在四处：**甲缝溢出的生长层**、**表面的纹路 / 苔藓 / 膜**、**剪影件的有机轮廓**（仍需硬表面）、**动态特效**（孢子飘散、雾气）。
> - ❌ 不允许：整体软烂、黏液质、无分面的肉块感、触须取代四肢——那是怪人（参见 Breed Gavv）。
> - **自检**：把图缩到指甲盖大小，还能看出「硬甲分件的块面」吗？看不出 → 加硬。

> ⚠️ **最终渲染材质约束（落进生图提示词时）**：无论母题材质选什么（玻璃 / 水晶 / 金 / 漆器…），**甲片基底统一为金属 / 陶瓷弹道装甲板**（效果最稳最高级）；母题元素（金 / 水晶 / 玻璃等）只作**小范围镶嵌与描边装饰**（纹章、铆钉、接缝线），**不得作为甲片主体大面积铺满**——大面积镀金 / 全水晶甲片会显得廉价（low）。覆盖率也要写：胸 / 肩 / 臂 / 腰 / 大腿 / 小腿均被甲片包裹，底衣仅活动关节露出。

### C. 变身机制（Henshin）—— **D9 锚点四连不可动，创新只能在后半段**
- **不可动**：取出道具 → 插入 / 嵌入腰间装置 → 明确机械操作（转 / 拉 / 按 / 盖印）→ 装置响应。
- **可创新**：① 道具是什么（换成母题里的物件）② 操作动作是什么 ③ 装置如何响应 ④ **之后的介质与生长**（见 `henshin-finisher-ability-engine.md`）。
- 具体可换的操作举例：转柄、拉杆、拍按钮、盖印、拧发条、掰开、吹响、咬合、**让道具被装置"吃掉"**、两端对拧、插入后反向弹出再按回。
- ⚠️ **不要**写成「凭空冥想 / 纯手势无道具 / 环境触发即变身」——那去掉了 D9 锚点，不再是假面骑士。零。

### D. 装甲生成（Armor manifest）—— 怎么"长"出来
从地面生长并攀附、从伤口渗出后凝固、从影子剥离立起、被光"编织"、从体内翻转出来、结晶化覆盖、被液体浸没后固化、被记忆逐层叠上、由尘埃吸附聚合成形、从背后展开成壳。

### E. 色彩策略 —— 不局限于红蓝金银
单色渐变（同色系深浅）、黑白 + 单一高饱和点缀、莫兰迪低饱和、金属氧化色（铜绿 / 锈红）、生物荧光（青绿 / 品红 / 电蓝）、故障色偏（RGB 分离）、负片反相、褪色胶片感。

> ⚠️ **配色三法则（落进生图提示词时必守）**——「大面积高饱和 = 塑料玩具感」是"low"的头号成因，但**解法不是把颜色全换成中性色**（那会抹平角色辨识度，五个骑士撞成一身）。正解是**面积比 + 明度结构 + 彩度发光化**：
> 1. **60 / 30 / 10 面积比**：
>    - **dominant 60%** = 有明度指向的中性色（陶瓷白 / 骨白 / 石板灰 / 哑光黑 / 石墨黑 / 铁灰…）。**每个骑士的 dominant 必须错开明度与冷暖**，这是除识别色之外的第二重辨识度（白虎=高调白、青龙=暗冷灰蓝、朱雀=暗暖哑光黑、玄武=暗重石墨、麒麟=暖亮骨白）。
>    - **secondary 30%** = **该角色的识别色**——**不是不用色，是把它"沉"下去**：降饱和、加深、改哑光。写 `deep jade-green` / `oxidized crimson` / `deep teal`，**不写** `emerald green` / `bright red` / `vivid teal`。
>    - **accent 10%** = 金属色（金 / 银 / 青铜 / 香槟金）+ visor 发光色。
> 2. **彩度发光化**：**饱和度交给「发光」，不要交给「材质」**。大面积曲面上铺高饱和色 + 高光 = 注塑塑料感；把彩度放到 **visor / energy channels / 自发光描边** 上，观感是"光"不是"塑料"，识别色照样一眼可辨。判据：材质写 **低彩度**（`deep / oxidized / matte [色] plates`），发光写 **高彩度**（`glowing [色] visor and energy channels`）。
> 3. **一色原则**：整套最多 **1 个识别色 + 1 个金属色 + 1 个发光色**；出现第 4 个颜色一律砍掉。

### F. 剪影放大件 —— 不止围巾与触角
尾迹、悬浮碎片环、破碎斗篷、残影手臂、背后光轮 / 日冕环、拖曳的锁链、菌伞、晶体簇、气体羽流、折叠屏般的背板、悬浮的环、垂落的缆线。

### G. 移动 / 动态特征 —— 不止奔跑
无摩擦滑行、瞬移残影、重力异常（能倒着走 / 贴墙）、液体般流动、分解后重组、骑乘自己的武器、跳跃后二次加速。

### H. 武器概念 —— 不止剑与枪
自己的一部分（肋骨化作刃、影子化作镰）、活物（共生体）、声音、绳 / 线、液体、一段被冻结的时间、自己的断肢、缠绕的绷带、共鸣的音叉。

### I. 代价 / 限制（D8 的想象力入口）
每次变身失去一种感官记忆、身体逐渐晶体化、必须在黑暗中才能维持、每次使用缩短寿命、必须听见某个声音、力量越强越接近怪物、变身后会忘记一个人的名字、只能在雨后现身。

### J. 音效 / 听觉签名（D11 的想象力入口 · **仅分镜流 B/C 使用，生图流 A 不碰**）

> ⚠️ **生图流不落地音效**：A 生图流产出的是静态角色设计图，听不见声音，因此本维度**不写进生图设计卡 / 生图提示词**。音效是分镜（B 变身流 / C 战斗流）资产，只在分镜提示词里落地（见 `henshin` 1.4）。

D9 四连**每一步**都应有一个口号式 call-out（装置在操作时喊出的单词 / 短语，区别于纯机械哔声）：取道具的启动口号（Vail"独角仙！"）、交互口号、操作口号（Vail 盖印"交易成立！"）、响应报号（喊出骑士名）+ 序列音 + 定格静默；必杀有命名 call。可创新项：每步口号的语言与音色（机械电子音 / 生物脉动 / 环境母题化）、必杀命名 call 的风格（与终结内核一致）、装置机械音的材质感（金属咔哒 / 玻璃碎裂 / 晶体共鸣 / 低频脉冲）、序列音的节奏（急促连珠 / 庄严慢板 / 倒放）、与母题同构的「音形」（回声用延迟叠音、日食用吞光后的静默、鮟鱇用低频脉动）。**每条骑士应有可一句话说出的听觉签名**，供分镜提示词调用——写出来是像什么声音、每步喊什么口号，而不是「很帅的音效」。

## 3. 组合方法（抽签式，防撞车）

```
独创骑士 = 1 拟态 + 1 材质 + 1 变身机制 + 1 装甲生成 + 1 色彩策略
           + 1 剪影件 + (1 移动特征) + (1 武器) + 1 代价
```
- **音效签名（D11）不进生图组合**——它是分镜流（B/C）资产，生图流（A）只产静态角色设计、听不见声音，落地见 `henshin-finisher-ability-engine.md` 1.4。
- **至少跨 4 个维度选非常规答案**（尤其是拟态 + 材质 + 变身机制）。
- 组合后必须能一句话说清这个骑士「是什么」——说不清就是母题不够锐利。
- 每生成一批，**拟态不得重复**；同批 5 个要覆盖不同母题类别（如天象 / 深海 / 抽象 / 日常 / 地质）。**且不得与「组合种子示例」表的 5 个母题重复**（那是 batch5 成稿，复用即撞车）。

### 组合种子示例（**写法范本，不是出题池** ⚠️）

## 4. 提示词写法（DNA 打底 + 想象注入）

> ⚠️ **主体必须是假面骑士，不是 Warframe 装甲。** 渲染风用 UE5 / Warframe 级的 PBR 与电影布光，但**主体身份是「假面骑士」**——腰带（变身 belt）+ 非人单眼 / 复眼头盔是两大不可替代的识别符号，必须在提示词里点名且做醒目。只写「biomechanical armor + Warframe aesthetic」而弱化腰带 / 头盔，模型会产出通用 Warframe 战甲，丢掉骑士身份。

1. **先画风锁定块**（见 `visual-style-and-character-design.md`，UE5 / Warframe）。
2. **再 DNA 打底**：这四项**必须出现英文描述**，且要把「假面骑士」身份写死——`henshin belt / driver buckle at waist`（腰带是假面骑士第一识别符号，做成**醒目、居中的大腰带扣**，不是小挂件）/ `glowing single-eye or compound-eye visor helmet`（非人眼，虫眼 / 单眼风）/ 分区或不对称 / 剪影放大件；提示词**首句必须点名 `Kamen Rider (仮面ライダー)`**，否则模型会退化成通用 Warframe 装甲。
3. **最后想象注入**：把 A–I 的选择写进材质、母题、机制描述里（用具体名词，不用抽象形容词）。
4. **避免撞车**：不写 `Build-style` / `Faiz-style` / `Decade-style` 这类指向既有骑士的词；改为写自己的母题名词。
5. **负面词**沿用 UE5 版，并加 `generic superhero armor, plain full-face helmet, human eyes`。

### 写法模板（英文，替换方括号）
```
Character design sheet of a Kamen Rider (仮面ライダー) — a masked rider hero, NOT a generic
Warframe / Destiny mech suit: [MATERIAL] [MOTIF]-inspired biomechanical armor, [MOTIF] motif
readable on helmet and chest, [COLOR STRATEGY], [SILHOUETTE PIECE]; a bold, central
**henshin belt / driver buckle** at the waist (the defining Kamen Rider signature, large and
glowing, not a small gadget); a bug-eyed or single-lens **visor helmet** (non-human compound
eye, no visible human eyes); [ASYMMETRY / PANELING]; [MOVEMENT / WEAPON hint]; UE5 cinematic
render, film grain, full body, hero stance, clean background, highly detailed, Warframe-grade
surface PBR (use Warframe as material/lighting quality, NOT as the subject identity).
```

## 6. 避坑：这些"想象"会让角色不像骑士

| 错误做法 | 后果 | 修正 |
|---|---|---|
| 去掉腰部装置 | 变成普通装甲英雄 | 必保留 driver（可改形态，但不能没有） |
| 用人类眼睛 / 露脸 | 变超级英雄 coser | 发光 non-human visor |
| 完全对称、无分区 | bland、没记忆点 | 强制一处不对称或分区 |
| 母题说不清 | 只是"花哨装甲" | 换更锐利的母题，并在头盔+胸甲重复它 |
| 直接挪用既有骑士配色/招式 | 撞车、没独创 | 母题与材质必须来自骑士 IP 之外 |
| 变身无代价无限制 | 角色扁平 | 至少加一条限制（D8） |
| 把角色做成纯机甲 / 纯怪物 | 不是骑士 | 保留人形 + 人类同一性 |

---

> **一句话**：DNA 定「它是骑士」，想象力定「它是哪一个、为什么非它不可」。
