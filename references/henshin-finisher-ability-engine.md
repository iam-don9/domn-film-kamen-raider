# 变身 / 终结技 / 技能系统 想象力引擎

> 本文件管**动态三件套**：变身怎么发生、终结怎么结算、技能从哪里长出来。
> **静态设计**（拟态 / 材质 / 配色 / 剪影 / 代价）见 `references/design-dna-and-imagination.md`。
> 核心立场：**这三项都必须由「母题」推出**，不能套通用模板。
> 判断标准：把母题换成另一个，这套变身/终结/技能如果还能原样用——就是失败的通用公式。

---

## 0. 三条总纲

1. **母题决定一切**：变身介质、终结机制、技能组，都必须Traceable到那个「可命名拟态」。
2. **代价必须可见**：D8 的代价不能只在设定里，要在变身过程、技能使用、终结结算里**被画出来**。
3. **每项都要有视觉签名**：写不出「这一招长什么样」，就说明想象不够具体，生成器也画不出来。

# 一、变身想象力引擎

## 1.1 锚点四连（不可动）+ 想象四段（可发散）

> ⚠️ **修正一个错误倾向**：「掏道具 → 插入 → 转旋钮」**不是该被抛弃的俗套，而是假面骑士的视觉锚点**（D9）。
> 平成以降 25 年从未变过——最新的 Gavv（2024–25）仍然是「**张开腰带嘴 → 插入饱藏 → 闭嘴 → 转侧面把手 → 按左侧按钮**」，连必杀技都还是「**转把手蓄能 → 拍按钮**」。
> **去掉它，就等于剪断观众认出「这是假面骑士」的那根线**，退化成通用变身。
>
> 正确姿势是：**仪式结构守旧，内容全部换新**——像爵士标准曲，和声进行不动，旋律随便写。

### 锚点四连（结构不可动，但每一格的**内容**都能换）

| 拍 | 不可动的结构 | 可创新的内容（母题化举例） |
|---|---|---|
| **① 取道具** | 拿出一个**可辨识的小道具** | 瓶罐 / 记忆体 / 硬币 / 卡带 / 饱藏 → 换成母题里的东西：**一块声石、一枚菌核、一片日食盘、一块镜刃、一颗诱饵光囊** |
| **② 交互** | 与**腰间装置**发生物理交互 | 插进插槽、塞进装置的"嘴"里、贴上腰部、扣进卡槽、被装置咬住、两端对嵌 |
| **③ 操作** | 一个**明确的机械操作** | 转柄 / 拉杆 / 拍按钮 / 盖印 / 拧发条 / 掰开 / 吹响 / 咬合 / **让道具被装置吃掉** / 插入后弹出再按回 |
| **④ 响应** | 装置给出**明确反馈** | 发光、报号（喊出形态名）、机械咬合声、反向输出、道具被嚼碎 |

### 想象四段（发散主战场：锚点之后的部分）

| 段 | 要回答什么 | 发散方向（举例） |
|---|---|---|
| **⑤ 代价 Cost** | 在这一刻付出什么（承接 D8）？ | 失去一种声音的记忆、被菌丝占据一寸、体温归零一段时间、遗落一块碎片、忘记一个名字、折寿 |
| **⑥ 介质 Medium** | 什么东西承载变化？ | 声波、孢子、影子、光束与倒影、液体（水 / 墨 / 树脂 / 血）、晶体、尘埃、铁锈、菌毯、雾、射线、绳索、记忆本身 |
| **⑦ 生长 Growth** | 装甲怎么出现？ | 攀附生长、从伤口渗出凝固、由影子剥离立起、被光编织、由体内翻出、结晶化覆盖、被液体浸没后固化、尘埃吸附聚合、记忆逐层叠加、自地面生长攀附 |
| **⑧ 定格信号 Tell** | 怎么知道变身完成？ | 最后一个碎片归位、光被完全吞尽、诱饵点亮、钟针重合、一声特定的回响后归于寂静 |

> **链路必须自洽**：③ 操作为何触发 ⑥ 介质？⑥ 为何以 ⑦ 这种方式生长？说不通就换。
> 例：**声石插入腰间装置 → 拧动（③）→ 装置共振发声（④）→ 声波（⑥）把黑曜石玻璃震碎 → 碎片沿声线排布成铠（⑦）→ 最后的回响落地（⑧）**。锚点完整，想象也完整。

> **硬表面法则（D10）在这里同样生效**：⑥ 介质可以是软的（声波 / 孢子 / 雾），但 ⑦ 生成的必须是**可辨的硬甲分件**。
> 孢子可以生成**陶瓷化的菌甲**，不能生成软烂黏液——那是怪人（参见反派 Breed Gavv 的黑污泥形态）。

## 1.2 五个反直觉设计法（最少用两个）

| 手法 | 说明 | 画面效果 |
|---|---|---|
| **微触发巨变** | 极小动作引爆极大变化 | 仪式感与压迫感，比"剧烈动作"更强 |
| **环境必需** | 必须在特定环境才能变身（黑暗 / 雨 / 镜面 / 回声空间 / 视线） | 环境成为演出的一部分，限制即戏剧 |
| **媒介先行** | 本体没动，**倒影 / 影子 / 回声先一步变身**，本体再去接收 | 双层演出，悬念感更强 |
| **渐进不可逆** | 每次变身留下永久痕迹（呼应代价） | 让观众看见"代价在积累" |
| **反向变身** | 不是"穿上装甲"，而是**褪去**什么（褪下人皮 / 剥落锈层 / 蒸发水汽）露出本体 | 反转期待，比"加装甲"更狠 |

## 1.3 示例：五条完整变身链（承接独创骑士）

| 骑士 | **锚点四连（不可动）** | 代价 | 介质 | 生长（必出硬分件） | 定格信号 |
|---|---|---|---|---|---|
| **回声** | 取出一枚**声石** → 嵌入腰间共振装置 → **拧动**（调音）→ 装置发出一声纯音 | 失去一种声音的记忆 | 声波 | 黑曜石被震成碎片，**沿声线排布咬合成硬甲** | 最后一个音节的回声落地 |
| **菌丝** | 取出一枚**菌核** → 按进腰部培养槽 → **压下压杆** → 菌核裂开、装置报号 | 身体逐渐被菌丝占据一寸 | 孢子 | 孢子涌出后**硬化成陶瓷化菌甲与几丁质菌伞**（不是软烂黏液） | 肩头菌伞张开并硬化到位 |
| **日食** | 取出一片**日食盘** → 嵌入腰带 → **旋转**使两盘错位咬合 → 光被吞、装置变冷 | 变身後体温归零一段时间 | 影子 | 影子立起成**黑曜石壳**包覆全身，金光从壳缝渗出 | 光被完全吞尽的一瞬 |
| **折光** | 取出一片**镜刃** → 插入腰带棱镜槽 → **掰断**一半（代价即操作）→ 折射光爆闪 | 每掰一次，现实里遗落一块碎片 | 倒影 | **倒影先一步成铠**，折射把装甲传回本体，碎片环悬停 | 本体与倒影完全一致的一帧 |
| **鮟鱇** | 取出一颗**诱饵光囊** → 挂上腰间咬合器 → **拧亮**（调亮度）→ 光囊亮起、四周变暗 | 只能在黑暗中维持 | 生物荧光 | 荧光膜沿脊椎蔓延，**骨甲在黑暗中显影成硬分件** | 诱饵光达到最亮 |

## 1.4 音效层（D11 听觉锚点）

> 音效是变身的「听觉孪生」：视觉上 D9 四连不可动，听觉上 D11 每步口号式 call-out 不可动。观众靠**看见道具操作 + 听见装置每步喊口号 + 报出名字**三重确认「这是假面骑士」。
>
> **口号式音效（call-out）= 装置在操作时喊出的单词 / 短语，区别于纯机械哔声**。D9 四连每一步都应至少有一个口号 call-out（取道具→启动口号、交互→交互口号、操作→操作口号、响应→报号），不是只在最后报个名。例：Vail 印章**启动**"独角仙！"→ **盖印**"交易成立！"→ 序列"灾厄涌现！破坏！世界！千奇百怪！假面骑士——Vail！"。

**变身五段链的音效分配**（以回声骑士为例，每段对应一个声音；生图不写音效，分镜才写）：

| 段 | 视觉 | 听觉（音效签名） |
|---|---|---|
| ① 取道具 | 取出声石 | 声石离手一声清脆「石鸣」 |
| ② 交互 | 嵌入共振装置 | 装置咬合的机械咔哒 |
| ③ 操作 | 拧动调音 | 调音连续滑音（pitch 上升） |
| ④ 响应 | 装置发纯音 + 报号 | **报号 call：「假面骑士——回声（Echo）！」**（延迟叠音，名字被反复反射） |
| ⑤ 代价 | 失去一种声音记忆 | 对应频段从环境「消失」的静默 |
| ⑥ 介质 | 声波 | 可见声波纹 + 同频嗡鸣 |
| ⑦ 生长 | 碎片咬合成铠 | 玻璃碎片碰撞的细碎高频 |
| ⑧ 定格 | 回响落地 | 最后一记回响衰减归零，**定格一瞬静默** |

**口号式 call-out 示例（Vail 2022，D9 四连每步）**：

| 步 | 视觉操作 | 口号式音效（call-out） |
|---|---|---|
| ① 取道具 | 取出印章 | "カブトムシ！"（独角仙，启动口号，喊出母题名） |
| ② 交互 | 印章嵌入腰带 | 机械咔哒（交互音） |
| ③ 操作 | 盖印 | "トランザクション！"（交易成立，操作口号，喊出动作结果） |
| ④ 响应 | 装置报号 | 序列"サイガイユウゲン！ハカイ！セカイ！センキヒャッカイ！カメンライダー・バイル！"（灾厄涌现！破坏！世界！千奇百怪！假面骑士——Vail！，报号 call） |

> 注意：口号不仅有「报号」那一声——① 取道具、③ 操作都有各自的口号式 call-out。这才是假面骑士变身器"会喊话"的精髓；只留报号 + 必杀名是漏了大部分。

**五位骑士音效签名**（报号 call 音色 / 序列节奏 / 必杀 call / 装置机械音）：

| 骑士 | 报号 call 音色 | 序列音节奏 | 必杀命名 call 风格 | 装置机械音 |
|---|---|---|---|---|
| 回声 | 延迟叠音（名字被反射多次） | 急促连珠、随声波起伏 | 「消声（Silence）！」报出被抽走之物 | 玻璃碎裂高频 |
| 菌丝 | 生物脉动（菌丝舒张窸窣） | 缓慢、生长感 | 「霉变爆发（Bloom）！」 | 陶瓷裂开闷响 |
| 日食 | 吞光后的静默（call 在寂静中响起） | 庄严慢板、由明转暗 | 「蚀（Eclipse）！」 | 金属遮板滑动沉重 |
| 折光 | 玻璃共振清亮 | 碎裂般跳进 | 「碎镜（Shatter）！」 | 棱镜咔哒转位 |
| 鮟鱇 | 低频脉冲（诱饵光声化） | 深海脉冲、忽明忽暗 | 「吞没（Devour）！」 | 颚部咬合湿重 |

**音效在提示词里怎么落地**：
- **语言默认（音频类）**：B/C 分镜流里的**音效 call-out、角色对白、旁白**一律**日语发音**（片假名 / 罗马字标注，如「エコー！」「サイレンス！」「デビル！」）；除非用户明确指定其他语言。A 生图流是静态图、不涉及音频。
- **A 生图流**：不写「伴随 XX 音效」（听不见）。改为在设计卡记载「音效签名」，并在装置外观**暗示音效反馈**（腰带有声纹纹路、报号时张开的口部栅格）；如需画面表达，用**视觉顿挫**（装置发光脉冲 = 报号瞬间）。
- **B/C 分镜流**：在分镜提示词写「音效层」——序列音、报号 call、必杀 call，并用画面顿挫（定格 / slow-mo / 张开的口部）同步。例：「Cam4 低角定格，装置报出『エコー！』的延迟叠音，全身装甲纹路亮起一圈声纹——画面静默 0.4s 后切战斗。」

# 二、终结技想象力引擎

> 现状问题：终结只有「骑士踢」和「武器必杀（装填→蓄光→斩击）」两种，且与母题无关。
> **铁律**：终结必须由母题推出；必须体现代价；必须有一个能被画出来的结算画面。

## 2.1 八大终结类型

| 类型 | 机制 | 母题化例子 | 适合母题 |
|---|---|---|---|
| **① 概念结算** | 不是物理打击，而是把骑士的规则/代价**转嫁**给敌人 | 让敌人体温归零后静止碎裂；抽走敌人的声音使其内部失压崩解 | 日食、回声 |
| **② 环境协同** | 终结必须调用特定环境 | 必须有镜面才能把敌人关进倒影；必须黑暗才能将其吞噬 | 折光、鮟鱇 |
| **③ 自损** | 以自身一部分为代价换取一击 | 断一臂化作刃刺入；燃烧一段记忆换取一击的威力 | 任何有 D8 的 |
| **④ 延迟** | 打击当下无事，倒计时后才结算 | 命中后不碎，三秒后体内孢子成熟撑爆 | 菌丝 |
| **⑤ 多重** | 不是一击，是多处同时/连续结算 | 残影从多个方向同时命中；回声从四面收束 | 瞬移/残影类 |
| **⑥ 倒放** | 把敌人的状态倒回去再结算 | 让敌人回到未被改造前的瞬间，再让它承受伤害 | 时间类 |
| **⑦ 收容** | 不杀死而是**封印** | 封进日冕光轮 / 锁进镜中 / 收进号角 | 日食、折光 |
| **⑧ 形态武器** | 身体本身成为攻击形态 | 把自身拉长成一柄楔贯穿；把自己化作一道波 | 回声、折光 |

## 2.2 踢与武器也必须母题化

保留「骑士踢 / 武器必杀」作为**动作外壳**，但內核必须换成母题化的机制：

| 骑士 | 终结外壳 | 母题化内核 | 结算画面 |
|---|---|---|---|
| 回声 | 声波炮 | 把敌人的"发声"抽走，使其在无声中自我崩解 | 敌人张开嘴却无声音，身体沿声波节线裂开 |
| 菌丝 | 骑士踢 | 踢击瞬间孢子沿接触点注入，延迟三秒后在体内成熟撑爆 | 敌人静止三秒，随后从內部迸裂出菌伞 |
| 日食 | 骑士踢 | 踢命中后把敌人的"光"吞掉，使其陷入绝对黑暗与低温 | 敌人褪成纯黑剪影，随后像玻璃一样碎裂 |
| 折光 | 武器必杀 | 把敌人关进镜像，再让镜像破碎，本体同步破碎 | 镜面裂纹蔓延到敌人身上，两者同时粉碎 |
| 鮟鱇 | 武器必杀（颚钳） | 诱饵光把敌人引入完全黑暗，一口吞下 | 黑暗中只剩诱饵光与颚部闭合的一瞬 |

> **自检**：把母题换成另一个，这一招还能用吗？能 → 推翻重来。

## 2.3 仍需遵守的底线（D7）

- 全场**只有一个**终结，不叠加多种。
- 终结从慢镜蓄力→结算→落点全景**同一镜内**完成（见 `battle-director-30s.md`）。
- 结算后有 0.2–0.4s 的破坏全景，之后不再追加动作。

## 2.4 必杀音效（命名 call，接 D11）

> 必杀的命名 call 不是装饰，是**终结内核的口播**——报出这一击「做了什么」，与变身报号 call 同构。

| 终结类型 | 命名 call 报出什么 | 例子 |
|---|---|---|
| 概念结算 | 被转嫁之物 | 「消声！」抽走敌人的发声；「蚀！」吞掉敌人的光 |
| 收容 | 封印之名 | 「碎镜！」把敌人关进镜像再打碎 |
| 形态武器 | 形态动作 | 「吞没！」自身化作一道波贯穿 |
| 自损 | 付出的代价 | 「燃忆！」燃烧一段记忆换取威力 |
| 延迟 | 成熟时刻 | 「绽放！」三秒后体内孢子撑爆 |

> 原则：**call 与终结内核一致**；不能用通用「Rider Kick！」替代（那等于没母题化）。节奏上，call 落在慢镜蓄力释放的瞬间，与画面顿挫同步。

# 三、技能系统想象力引擎

> 现状问题：只有「武器类型 → 打法表（接近/进攻/追击/闪避/防守/反击/重击）」，是通用的，与角色无关。
> **每个骑士应有**：1 个核心能力 + 2–3 个派生技能 + 1 个限制 + 1 个被动异状。全部由母题长出。

## 3.1 六类能力方向

| 类别 | 能力是什么 | 例子 | **视觉签名**（必须画得出） |
|---|---|---|---|
| **感知** | 非视觉地"看见" | 回声定位、听心跳辨位、热感应、影子感知 | 空气中扩散同心波纹；胸口亮起敌人轮廓 |
| **物质操作** | 改变接触物的状态 | 让接触面玻璃化 / 锈蚀 / 结晶 / 腐蚀 / 生长 | 接触点出现材质转化的蔓延边界，边界缓慢推进 |
| **位移** | 非常规移动 | 无摩擦滑行、残影瞬移、重力异常（倒着走 / 贴墙）、液态流动 | 身后拖曳残影；地面不留足迹；雨水与尘埃沾不住身 |
| **规则** | 局部改写物理规则 | 范围内失声 / 失重 / 静止 / 失温 | 空间浮现半透明「域」，域内物体行为异常 |
| **共生** | 活体或可离体部件 | 武器是活的、部分身体可离体回收、派出分身 | 部件有独立微动（呼吸般起伏、自行转向） |
| **环境** | 依赖或调动环境 | 召唤雾、让水倒流、操纵阴影之手、把环境变成自己的感知器官 | 环境要素被动员的大幅运动（雾涌、水逆流） |

## 3.2 技能组模板（每个骑士填一份）

```
核心能力：<由母题直接推出的一句话>
派生1：<核心能力的攻击化>
派生2：<核心能力的防御/位移化>
派生3：<核心能力的辅助/环境化>
限制：<对应 D8 代价的具体触发条件>

```

# 四、组合与自检

## 4.1 三件套必须互相咬合

```
母题
 ├→ 变身：介质与生长方式 = 母题的物理行为
 ├→ 终结：结算方式       = 母题推到极限
 └→ 技能：核心能力       = 母题的日常化应用
```
- 三者**必须指向同一个母题**；出现「母题是回声，但技能是挥剑砍」= 失败。
- 变身的代价 = 技能的限制 = 终结的自损来源（三个地方要一致）。

## 4.2 自检清单

- [ ] 变身五段链（触发→代价→介质→生长→定格）每段都答得出来？
- [ ] 用了 ≥2 个反直觉手法？
- [ ] 终结能被一两句话说清，且**换成别的母题就不成立**？
- [ ] 终结体现了代价（自损 / 限制 / 转嫁）？
- [ ] 技能组有「核心 + 2–3 派生 + 限制 + 被动异状」？
- [ ] 每个技能都有**视觉签名**（能写进生图提示词）？
- [ ] 变身介质 / 终结机制 / 技能核心是否一致指向同一母题？
- [ ] 终结是否只有一个（不叠加）？是否在同镜内完成？

## 4.3 避坑

| 错误 | 后果 | 修正 |
|---|---|---|
| 变身介质与母题无关 | 变身只是特效表演 | 介质必须是母题的物理行为（声波特化/孢子传播/光被吞） |
| 终结是通用踢 / 通用炮 | 疲劳、没记忆点 | 换母题化内核（见 2.2） |
| 技能写成"武器类型打法表" | 与角色无关 | 改成核心能力 + 派生 + 限制 + 被动异状 |
| 技能写不出画面 | 生成器画不出来 | 每个技能必须配视觉签名 |
| 代价只写在设定里 | 观众看不见 | 代价必须在变身/技能/终结里被画出来 |
| 终结叠加多种 | 高潮散掉 | 全场只留一个终结，且二选一分支只走一支 |

---

> **一句话**：变身是母题的**物理行为**，技能是母题的**日常应用**，终结是把母题**推到极限的一次结算**。
